## 狼人杀助手 — 建表SQL脚本

**需求**：把项目所需的全部表的创建SQL放到 `db/mysql` 目录下。

**产出**：`/Users/jinbiao.zhang/IdeaProjects/AI-Learn/werewolf-assistant/db/mysql/schema.sql`

包含4张表：
1. `werewolf_game` — 历史对局表（uk_session_uuid, idx_created, idx_status）
2. `werewolf_snapshot` — 对局快照表（FK → werewolf_game, ON DELETE CASCADE）
3. `werewolf_live_session` — 实时会话表（uk_session_uuid, idx_started_at, idx_status）
4. `werewolf_live_event` — 实时事件表（FK → werewolf_live_session, ON DELETE CASCADE, idx_session_day）

所有表使用 InnoDB + utf8mb4 + utf8mb4_unicode_ci，时间字段用 DATETIME(6)，大文本用 LONGTEXT。
