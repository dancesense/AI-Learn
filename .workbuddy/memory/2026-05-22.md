# 2026-05-22 工作记录

## werewolf-assistant 第二次测试问题修复

### 1. 卡顿闪退优化（最高优先级）
- **renderSpeechList 全量重建DOM** → 改为增量更新：引入 `cardCache` 缓存卡片元素，仅更新变化的属性
- **添加防抖** → `scheduleRender()` 使用 `requestAnimationFrame` 代替直接调用
- **SSE流式更新节流** → `STREAM_THROTTLE_MS=150ms`，避免每个chunk都触发DOM重绘
- **VAD轮询优化** → 从250ms降到400ms，减少CPU占用
- **关键词正则预编译** → `identityRegex`/`actionRegex` 替代循环replace
- **内存上限** → AI总结限5条，发言限10段
- **页面可见性监听** → `visibilitychange` 事件，切后台自动暂停录音

### 2. AI总结重构为三板块格式
- 后端prompt新增 `threeBlockFormat`：`【自称】【评价】【期望】`
- 前端新增 `formatThreeBlocks()` 函数，将三板块渲染为带颜色标记的卡片
- CSS：`.three-blocks` 布局，`.block-claim`(黄)、`.block-eval`(蓝)、`.block-expect`(红)
- dataPanel类型保持原有概率格式不变

### 3. 板子配置修复
- `CreateLiveSessionRequest` 新增 `roleComposition` 字段 (Map<String, Integer>)
- `LiveChunkRequest` 新增 `roleComposition` 字段
- `WerewolfLiveSessionEntity` 新增 `roleComposition` TEXT字段存储JSON
- `defaultRoleComposition()` 新增从JSON解析的优先路径
- 前端 index.html 每个模式卡片添加 `data-role-json` 属性
- sessionStorage 存储 `werewolf_role_composition`，analysis.js 读取并传给后端
- 网易六人局配置：`{"狼人":2,"平民":2,"预言家":1,"猎人":1}`

### 4. 语音识别改善
- 静音超时 1800ms → 2500ms，避免过早截断
- 声音阈值 0.024 → 0.015，更容易检测到声音
- 最低录音时长 1s → 0.5s
- 错误恢复延迟 500ms → 1000ms，更稳定
- 新增录音状态文本：录音中显示"录音中 ●"，识别中显示"语音识别中..."
- MediaRecorder 启动前清理旧实例

## 自定义对局配置功能

### 功能
- 首页模式选择弹窗新增「⚙️ 自定义对局」卡片（占2列宽度）
- 选中后展开自定义配置面板：人数设置（4~18人，±按钮）+ 角色配置（7种角色，±按钮）
- 人数变化时自动按规则分配角色（狼人≈1/3，预言家1，6人+女巫1，9人+猎人1，12人+守卫1，余为平民）
- 实时汇总提示：✅ 配置完成 / ⚠️ 还需分配X个 / ❌ 角色超出
- 开始游戏验证：角色总数须等于人数，至少1个狼人阵营
- 验证失败时弹窗副标题变红提示2.5秒

### 关键实现
- `autoAssignRoles(n)` 根据人数智能分配默认角色
- `customRoleConfig` 存储当前自定义角色配置
- `renderCustomRoleList()` 动态渲染角色行和加减按钮
- `getCustomRoleJson()` 生成JSON传给 sessionStorage → analysis.js
- modeName 格式：`自定义{N}人局`

### 文件变更
- `index.html` — 新增自定义模式卡片、配置面板HTML、完整JS交互逻辑
