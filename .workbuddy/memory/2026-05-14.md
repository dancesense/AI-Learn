## MySQL 环境搭建 + 项目运行

### 数据库环境
- **安装方式**：Homebrew 安装 MySQL 9.6 (`brew install mysql`)
- **Docker**：本机未安装 Docker Desktop（brew cask 安装需要 sudo 创建目录，环境不支持），改用 Homebrew 直接安装 MySQL
- **MySQL 连接**：localhost:3306, root/root
- **数据库**：`werewolf_assistant`，已导入 `schema.sql`（4张表：werewolf_game, werewolf_snapshot, werewolf_live_session, werewolf_live_event）
- **注意事项**：Homebrew 安装的 MySQL 默认无 root 密码，需要 `ALTER USER` 设置密码为 root 以匹配项目配置

### 项目运行
- **启动命令**：`cd /Users/jinbiao.zhang/IdeaProjects/AI-Learn && SERVER_PORT=8012 mvn spring-boot:run -pl werewolf-assistant`
- **端口问题**：环境变量 `SERVER__PORT=62475`（WorkBuddy注入）会覆盖 application.yml 的 `server.port=8012`，需显式设置 `SERVER_PORT=8012` 来覆盖
- **验证**：`curl http://localhost:8012/werewolf/history/stats` 返回 `{"totalGames":0,"closedGames":0,"winGames":0,"winRate":0}`
